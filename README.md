# Triad stimuli projects

This repository contains two independent stimulus projects:

- [`alice-expanded-triads/`](alice-expanded-triads/): the current pipeline for
  expanding the 30-object ALICE stimulus set across all available textures.
  It contains its own code, assets, Blender bundle, generated outputs,
  documentation, logs, and reproducibility materials.
- [`cue-conflict-triads/`](cue-conflict-triads/): reserved for the collaborator's
  separate cue-conflict stimulus project. It is intentionally empty.

Each project should keep its own scripts, dependencies, data, documentation, and
outputs inside its folder. Only repository-wide files belong at this level.
